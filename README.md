# Tasnim Royal CRM

CRM داخلی مؤسسه فرهنگی هنری تسنیم رویال.

## هدف
ساخت یک CRM فارسی، RTL، موبایل‌محور و امن برای مدیریت مخاطبین، پیگیری‌ها، وظایف، دوره‌ها، ثبت‌نام‌ها، پرداخت‌ها و گزارش‌ها.

## معماری
- Next.js 16 / App Router
- TypeScript
- Tailwind CSS v4
- Supabase / PostgreSQL / Auth / RLS
- PWA و mobile-first
- رابط فارسی RTL با Vazirmatn

## ماژول‌ها
- داشبورد
- بانک اطلاعات / مخاطبین
- پروفایل مخاطب و فعالیت‌ها
- پیگیری‌ها
- وظایف
- دوره‌ها و ثبت‌نام‌ها
- پرداخت‌ها
- گزارش‌ها
- تنظیمات و مدیریت نقش‌ها (Admin)

## کنترل‌های مهم
- احراز هویت با Supabase Auth
- کنترل دسترسی با RLS و نقش‌های admin / manager / sales / support / viewer
- جلوگیری از ثبت شماره موبایل تکراری با نرمال‌سازی شماره‌های ایرانی
- کنترل ظرفیت دوره در سطح دیتابیس
- سازگاری مخاطب و ثبت‌نام در پرداخت‌ها
- محافظت از آخرین مدیر فعال سیستم
- عدم ذخیره رمز عبور در سورس‌کد یا GitHub

## مرزبندی
این Repository برای CRM است و نباید Test Engine، Talent Scoring Engine، Recommendation Engine یا حسابداری کامل را داخل هسته CRM پیاده‌سازی کند. اطلاعات استعداد در صورت نیاز به‌صورت read-only از لایه مربوطه مصرف می‌شود.

## وضعیت
هسته CRM پیاده‌سازی شده و CI شامل typecheck، lint و production build سبز است. برای اتصال نهایی به داده‌های واقعی، migrationهای Supabase طبق `SETUP.md` اجرا شوند.
