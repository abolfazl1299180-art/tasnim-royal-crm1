# Tasnim Royal CRM

CRM داخلی مؤسسه فرهنگی هنری تسنیم رویال.

## قابلیت‌ها
- داشبورد مدیریتی و اقدام سریع
- بانک اطلاعات مخاطبین با جستجو، فیلتر و صفحه‌بندی
- پروفایل مخاطب و تاریخچه تعاملات
- قیف فروش از سرنخ تا مشتری
- برچسب‌گذاری مخاطبین
- پیگیری‌ها و وظایف تیم
- دوره‌ها، ثبت‌نام‌ها و پرداخت‌ها
- گزارش‌های مدیریتی
- Audit Log برای ردیابی تغییرات حساس
- نقش‌ها و سطح دسترسی با Supabase RLS
- PWA و mobile-first

## معماری
- Next.js 16 / App Router
- TypeScript
- Tailwind CSS v4
- Supabase / PostgreSQL / Auth / RLS
- رابط فارسی RTL با Vazirmatn

## مرزبندی
این Repository برای CRM است و نباید Test Engine، Talent Scoring Engine، Recommendation Engine یا حسابداری کامل را داخل هسته CRM پیاده‌سازی کند. اطلاعات استعداد در صورت نیاز به‌صورت read-only از لایه مربوطه مصرف می‌شود.

برای راه‌اندازی دیتابیس و حساب مدیر، `SETUP.md` را دنبال کنید.
