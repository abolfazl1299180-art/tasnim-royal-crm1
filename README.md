# Tasnim Royal CRM

CRM داخلی مؤسسه فرهنگی هنری تسنیم رویال.

## هدف
ساخت یک CRM فارسی، RTL، موبایل‌محور و امن برای مدیریت مخاطبین، پیگیری‌ها، وظایف، دوره‌ها، ثبت‌نام‌ها، پرداخت‌ها و گزارش‌ها.

## معماری هدف
- Next.js 16 / App Router
- TypeScript
- Tailwind CSS v4
- Supabase / PostgreSQL / Auth / RLS
- PWA و mobile-first
- رابط فارسی RTL با Vazirmatn

## ماژول‌ها
- داشبورد
- بانک اطلاعات / مخاطبین
- پروفایل مخاطب و فعالیت‌ها
- پیگیری‌ها
- وظایف
- دوره‌ها و ثبت‌نام‌ها
- پرداخت‌ها
- گزارش‌ها
- تنظیمات و مدیریت نقش‌ها (Admin)

## مرزبندی
این Repository برای CRM است و نباید Test Engine، Talent Scoring Engine، Recommendation Engine یا حسابداری کامل را داخل هسته CRM پیاده‌سازی کند. اطلاعات استعداد در صورت نیاز به‌صورت read-only از لایه مربوطه مصرف می‌شود.

## وضعیت
Repository تازه‌سازی‌شده و آماده ورود کد واقعی پروژه است.
